# VR Debugger Research Poster

In the summer of 2026, I was fortunate enough to be awarded the NSERC USRA and receive funding to work on a VR debugger, as well as create a protocol to test it against other readily available debuggers. Under the supervision of Dr. Meiying Qin and Dr. Sonya Allin, I  read literature on embodied cognition, VR-based learning, and programming error categories, then created a VR debugger in Unity for the Meta Quest 3, as well an experimental protocol to test it with. This protocol has been approved, and trials are set to begin in Fall 2026. The work done during the summer was summarized via this poster, which was presented at the 2026 Lassonde Undergraduate Research Conference.
